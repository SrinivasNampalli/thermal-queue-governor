# Thermal Queue Governor: focused claim-level technical review

Review date: **9 September 2026**. This is a bounded technical prior-art review of the eleven existing [discussion claims](../docs/CLAIMS_DISCUSSION_DRAFT.md), not a patentability, freedom-to-operate, or filing opinion. No application was filed and no third party was contacted. The [search and access log](PATENT_SEARCH_LOG_2026-09.md) records the queries, documents inspected, access failures, and remaining coverage limits. The earlier `prior_art_challenge.md` is preserved as a historical review.

## Decision

**The evidence does not support calling TQG unique or establishing a patentable invention.** Its broad ingredients have substantial documented overlap. The useful narrow discussion is the exact interaction of one-sided censor-consistent state bounds, an immutable accepted FIFO, every-prefix feasibility, a greatest admissible grid effort, and a verified zero-input tail in a positive scalar model. No inspected primary document was identified as disclosing that entire exact combination together. That limited search result is not a novelty guarantee, and the combination challenge remains strong.

This review adds particularly relevant challenges: an older motor patent derives current limits from predicted thermal power, including a square-root operation; another uses voice-coil temperature and cooling delay when selecting pending commands. Their specific disclosures make “thermal budget,” “square-root current cap,” and “temperature-aware command queue” weak standalone distinctions. These are technical comparisons, not assertions that their complete claims cover TQG. See P1 and P2 below.

## Exact subject reviewed

The implemented `interval_queue` policy in [governor.py](../src/governor.py) maintains a finite interval for nonnegative temperature rise, uses `x_next = a*x + b*u² + w`, intersects it with the observation-consistent set, predicts all already accepted FIFO actions, and appends one admissible quantized action. Its model constructor checks `w_max/(1-a_max) <= R`. `advance` uses a caller-asserted applied action. Invalidity is latched locally.

The equations discussed here describe ideal arithmetic. The implementation uses `1e-9` comparison tolerances and a `1e-12` grid-floor adjustment; it does not use directed rounding. Neither this review nor the existing simulation results establishes a strict machine-arithmetic enclosure theorem.

This is a synchronous software contract. The code does **not** authenticate acknowledgments, verify physical current, enforce wall-clock command expiry, reject network replay, calibrate a motor, or establish winding/hotspot or intersample safety. The diagnostic decision counter is not an execution permit. A virtual motor experiment remains a simulation; it cannot become physical motor validation by running on a VM or adding hardware graphics.

## What might be worth developing

The most plausible narrow research subject is **preserving the relationship between an irreversible accepted heat-producing prefix and a censor-consistent bound at the moment of admission**. The source code already expresses that relationship in a small, inspectable scalar calculation. However, none of the current empirical results establishes that this combination gives an unexpected result over the strongest properly adapted predecessor. Breaking an observer on purpose or omitting queued inputs provides mechanism evidence, not proof that all reasonable prior controllers fail.

Two distinctions should be tested without inflating them into delivered functionality:

1. **Present implementation, stronger evidence needed:** compare the exact finite-prefix/grid/zero-tail procedure against a correctly formulated constrained predictor with the same sensing, uncertainty, and immutable queue assumptions. Match action grid, admissible information, fallback assumptions, and computation budget. Report equivalence if the decisions coincide; do not tune the competitor into failure. Examine extended clipping and cases where a queued prefix already makes recovery impossible.
2. **Future proposal, not implemented by the eleven claims:** maintain a sound set of possible applied-action histories when acknowledgments or timing are uncertain, then certify admission against every consistent history and a physically justified fallback. L3 and L6 already make history/network uncertainty and buffered continuation substantial prior-art obstacles. Merely adding timestamps, tokens, expiry, or acknowledgments is not enough. A distinct technical result and new support would have to be demonstrated before claiming such an extension.

For virtual motor validation, a more detailed plant can reveal whether the scalar observer's assumptions survive sensor lag, multiple thermal nodes, cooling changes, or mismatched actuation. It cannot establish real parameter bounds, sensor placement, physical protection, or legal uniqueness. Any extension must retain negative cases, avoid feeding hidden simulated truth to the controller, and label post-review experiments separately from the frozen original study.

## Confidence and remaining uncertainty

This review supports **high confidence in broad overlap** and **low confidence in any patentability conclusion for the narrow combination**. It neither establishes that an exact full disclosure is absent nor concludes that every narrower claim necessarily fails. A claim-focused professional review should now examine the exact combination, supported human contributions, public-disclosure chronology, and relevant jurisdiction using the actual cited documents.

The search did not complete classification/citation closure, non-English full-text review, all patent families, prosecution histories, or current legal-status checks. Two recent secondary-only leads could not be verified from a primary publication and are quarantined in the log. They are not used to claim an exact match or a confirmed date. The supplied paper's authorship/publication history and the repository's actual public-disclosure dates are separate factual questions; an author credit is not a determination of patent inventorship.
