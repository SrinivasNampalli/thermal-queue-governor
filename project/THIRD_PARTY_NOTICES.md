Citation metadata identifies the project maintainer; it is not an inventorship or rights-transfer record.

The supplied research paper is attributed in the manuscript and source audit. Its code and raw data were not imported or redistributed. A publicly readable GitHub repository does not by itself supply a reuse license.

Python and its standard library execute the simulation. ReportLab, pypdf, Pillow, Poppler and system Arial fonts support export and inspection. Their installed license terms remain applicable; dependency binaries and proprietary font files are not redistributed. The spreadsheet builder uses the bundled artifact tool. No third-party source implementation is copied into the governor.

Their publisher provenance, exact versions, and license notices are recorded in [the demo's third-party notices](../demo/THIRD_PARTY_NOTICES.md). The offline download embeds those libraries; the public build serves deferred local copies with integrity checks. These licenses remain applicable regardless of the rights notice for original project materials.
